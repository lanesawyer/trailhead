# Naming ideas

> **Undecided.** Brainstormed names, not what anything is called. The one exception is grades, which are decided.

Undecided. The theme is PNW hiking and climbing, to match Trailhead. With the factory built into Trailhead, these work as names for its parts.

| Name | Meaning | Fits |
| --- | --- | --- |
| Trail Crew | Volunteer teams that build and maintain trails | The factory: the crew does the work Trailhead organizes |
| Ticklist | A climber's list of routes to send | The todo client |
| Ranger | Backcountry ranger | In-sandbox daemon |
| Belay | Holding the rope so nothing climbs unprotected | Review gate |
| Waterbar | Drainage bar that keeps water from wrecking a trail | Verification gate |
| Grade | Climbing's Yosemite Decimal classes, by exposure | A change's risk tier (decided, [review.md](review.md#grades)) |
| Treeline | Where routine ends and exposure begins | The line between grades that auto-merge and grades that need a human (decided) |
| Lookout | PNW fire lookouts | Observability |
| Cairn | Rock-pile trail marker | Checkpoints |
| Bivy | Emergency overnight shelter | Suspended, resumable sandbox |
| Summit Register | Logbook every party signs | Event log |
| Pulaski | Trail-building tool, half axe and half adze, named for ranger Ed Pulaski | Factory or binary name |
| McLeod | Rake-hoe that pairs with the Pulaski | Component |
| Rope Team | Climbers roped together, checking each other | Agents reviewing each other |
| Switchback | Climbing by zigzagging back and forth | Retry loop |
| Traverse | Crossing a route step by step | Orchestrator |
| Packstring | A line of pack animals hauling loads | A fleet of workers |
| Scramble | Fast progress over rough ground | Factory |
| Puncheon | Plank boardwalk crews build over wet ground | Factory |
| Turnpike | Raised trail section through bog | Factory |
| Tread | The trail surface crews build | Factory |
| Larch | The PNW's golden autumn conifer | Factory or crate name |
| Talus | Broken-rock field crossed one stone at a time | Factory |
| Tarn | Small alpine lake | Factory |
